# Experiments

Run every experiment in the paper and generate all of its tables and figures:

    scripts/run_all_experiments.sh PROCESSES [GPU...]

for example `scripts/run_all_experiments.sh 12`, or `scripts/run_all_experiments.sh 12 0 1`
to use GPUs 0 and 1.

An experiment whose results are saved is not rerun, so with the results checked in here the
script takes about a minute, needs no GPU and no CAPAL checkout, and only regenerates the
tables and figures. To rerun something, delete its results with the commands below and run
the script again.

It needs `graphviz`. Rerunning a CAPAL experiment also needs
[CAPAL](https://github.com/lkwargs/CAPAL) cloned at `../capal`, at the commit
`orthogonal_dfa/capal_official/adapter.py` pins. Rerunning a neural step needs a GPU.

Tables and figures are byte-identical across reruns on one machine. Another machine can
differ slightly: graphviz spaces the DFA drawings by whichever font `Helvetica` resolves to,
and PDFs depend on the matplotlib version.

## What produces what

Times are the saved runs' totals, before dividing by `PROCESSES` or GPUs.

| Paper | Results | Tables and figures | Time |
|---|---|---|---|
| Comparison to CAPAL | `data/capal/{capal_benchmarks,our_benchmarks}.json` | `figures/capal-comparison/{benchmark_grid,query_cost,success_rates}.tex` | 1.5 h |
| Hyperparameter sweep | `data/capal/wall_sweep.json` | `figures/capal-comparison/hyperparameter_sweep.tex` | 21 h |
| Matched query budget | `data/capal/matched_budget.json` | `figures/capal-comparison/matched_budget.tex` | 1 h |
| Random suite | `data/random_minimal/{targets,results}/` | `figures/random-minimal/{summary.tex,queries_vs_*.pdf}` | 28 h |
| Random suite, CAPAL | `data/random_minimal/capal_results/` | `figures/random-minimal/capal_successes.tex` | 43 h |
| Luhn | `data/luhn/results/` | `figures/luhn/{summary.tex,examples.tex,luhn_dfa.pdf}` | 15 min |
| Neural | `data/neural/length_oracles/` | `figures/length-oracles/` | 51 GPU-h |

`success_rates.tex` is not in the paper. The paper's other figures are illustrations,
generated by its own build.

## Rerunning experiments

Run these in bash from the repository root, then rerun the script. Saved results are reused without
checking the code that made them, so delete them after changing a learner or a sampler.

### CAPAL comparison

The matched budget is the queries E-L* spent in `our_benchmarks.json`, so it has to be
rerun whenever E-L*'s cells there are.

```bash
# everything
scripts/capal_delete_results.sh

# CAPAL's benchmarks, both learners
rm data/capal/capal_benchmarks.json

# our benchmarks, both learners
rm data/capal/our_benchmarks.json data/capal/matched_budget.json

# hyperparameter sweep
rm data/capal/wall_sweep.json

# matched budget
rm data/capal/matched_budget.json

# only E-L*'s cells (needs jq), after changing E-L* or its preconditions
for f in data/capal/capal_benchmarks.json data/capal/our_benchmarks.json; do
    jq '.cells |= map(select(.learner != "E-L*"))' "$f" > "$f.new"
    mv "$f.new" "$f"
done
rm data/capal/matched_budget.json
```

### Random suite

```bash
# E-L*
rm -r data/random_minimal/results

# E-L* at one noise level
rm data/random_minimal/results/*_eta0.30_seed0.json

# E-L* on one size of target
rm data/random_minimal/results/n18_*

# CAPAL
rm -r data/random_minimal/capal_results

# new targets, after changing the sampler: both learners' results are on the old ones
rm -r data/random_minimal/targets data/random_minimal/results data/random_minimal/capal_results
```

### Luhn

```bash
# every seed
rm -r data/luhn/results

# one seed
rm data/luhn/results/luhn_len16_eta0.30_seed0.json
```

### Neural

Run these in one shell, so that `D`, `R` and `drop_runs` carry through. `R` holds each run's own files
until they are added to `runs.json`, and a run with files there is not rerun.

The residual runs start from the flat runs' DFAs, and `residual_products.json` is computed
from the residual runs and the labels, so each command below also deletes what depends on
what it deletes.

```bash
D=data/neural/length_oracles
R=scratchpad/length_oracle_runs
drop_runs() {  # drop_runs ORACLE...: removes those oracles' rows from runs.json (needs jq)
    jq -c --args '$ARGS.positional as $o
        | (.runs, .restarts) |= map(select(.oracle | IN($o[]) | not))' \
        "$@" < "$D/runs.json" > "$D/runs.json.new" && mv "$D/runs.json.new" "$D/runs.json"
}

# all the runs
rm -rf $D/runs.json $D/residual_products.json $R

# the improperly calibrated runs
drop_runs saw
rm -rf $R/saw_s*

# the correctly calibrated runs, and the residual runs after them
drop_runs flat residual
rm -rf $R/flat_s* $R/residual_s* $D/residual_products.json

# the residual runs
drop_runs residual
rm -rf $R/residual_s* $D/residual_products.json

# the products of the residual runs
rm $D/residual_products.json

# the labels, and the products scored on them
rm $D/labels.npz $D/residual_products.json
rm -r ~/.cache/permacache/orthogonal_dfa/experiments/length_oracles/label

# accept rates on random strings
rm $D/random_strings.json
```

The neural steps also keep intermediate values in permacache, keyed on their arguments and
the model rather than on the code. After changing how the oracles are fit or how centred
scores are computed, also delete these, which takes the oracles' fits with them:

```bash
# every neural cache
rm -r ~/.cache/permacache/orthogonal_dfa/l_star/examples/gate_composition_residual \
    ~/.cache/permacache/orthogonal_dfa/l_star/examples/spliceai_oracle \
    ~/.cache/permacache/orthogonal_dfa/experiments/length_oracles
```
